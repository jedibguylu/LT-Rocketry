# LT-Rocketry
Repository for the Lane Tech Rocketry Club Rockets For Schools competition code. Started for the 2027 project.

**DO NOT COMMIT TO MAIN BRANCH WITHOUT TECH LEAD APPROVAL**

The goal of the project is to make an autonomous boat that can be dropped from a rocket and find its way back to shore by itself.
https://docs.google.com/document/d/1JcKzZzTIuOWlB71hLyqA7uwra-cOzHJsCKMjsvwLLzI/edit?tab=t.0

Steps to getting stuff to production:
1. Make sure your thing hasn't already been done and is still needed
2. Write it and make sure it compiles (Use codeHS or https://app.arduino.cc/  to check if it compiles)
3. Make a new project branch (or continue one) and upload your file
4. Tell tech lead you need a merge approved
